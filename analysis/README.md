# Signal Analysis

This directory contains the Python tools used to process and analyze the
433.92 MHz RF measurements collected by the ESP32 receiver.

## `signal_analysis.py`

The script processes the structured measurement data generated by
`pulse_capture.ino`.

The analysis includes:

- measurement data parsing and validation
- signal code identification
- delay statistics
- short and long pulse statistics
- pulse-pair validation
- binary signal decoding
- typical signal frame visualization
- bit-pattern visualization
- generation of cleaned measurement data
- generation of a protocol summary

## Analysis workflow

```text
ESP32 receiver
      ↓
pulse_capture.ino
