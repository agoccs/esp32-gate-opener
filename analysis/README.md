# Signal Analysis

This directory contains the Python tools used to process and analyze the
433.92 MHz RF measurements collected by the ESP32 receiver.

The analysis includes:

- measurement data parsing
- signal timing analysis
- delay statistics
- short and long pulse statistics
- decoded bit pattern analysis
- signal visualization
- generation of summary data

The analysis is based on the structured measurement data generated by
`pulse_capture.ino`.

Raw measurements containing reproducible gate-control information are
not included in the public repository.
