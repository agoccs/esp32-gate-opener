# Signal Analysis

This directory contains the Python tools used to process and analyze the
433.92 MHz RF measurements collected by the ESP32 receiver.

## `signal_analysis.py`

The script processes the structured measurement data generated by
`pulse_capture.ino`.

The analysis includes:

- measurement data parsing and validation
- signal code identification
- delay statistics
- short and long pulse statistics
- pulse-pair validation
- binary signal decoding
- typical signal frame visualization
- bit-pattern visualization
- generation of cleaned measurement data
- generation of a protocol summary

## Analysis workflow

```text
ESP32 receiver
      ↓
pulse_capture.ino
      ↓
Structured measurement data
      ↓
signal_analysis.py
      ↓
 ┌───────────────┬────────────────┬─────────────────┐
 │ Signal codes  │ Pulse timing   │ Bit patterns    │
 │ Delay         │ Statistics     │ Frame timing   │
 └───────────────┴────────────────┴─────────────────┘
      ↓
Analysis results

Input data

The script reads measurement data generated by the ESP32 receiver.

Each measurement contains the button, remote control and sample
identifiers together with the decoded signal information and raw pulse
timings.

The input data is expected in the CSV-compatible format generated by
pulse_capture.ino.

Output

The analysis generates:

cleaned measurement data
delay statistics
short and long pulse statistics
typical signal frame plots
measured bit-pattern plots
a protocol summary

The generated files are stored in the analysis output directory.

Protocol analysis

The current analysis is based on the observed RCSwitch Protocol 11
signal structure.

For the analyzed signal:

the signal contains 12 bits
bit 0 is represented by a short + long pulse pair
bit 1 is represented by a long + short pulse pair
the timing of the pulses is derived from the measured signal delay
Data security

Raw RF measurements capable of reproducing a specific gate-control signal
are not included in the public repository.

Only the analysis software and the methodology are published.
